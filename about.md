# Writeon Demo

A demo website for [Writeon](https://github.com/grisse/jekyll-theme-writeon), a minimal Jekyll theme for content-focused blogs.

**Write first. Design less.**

This site demonstrates Writeon's layout, typography, and writing-focused reading experience. It keeps the design simple and puts articles first.

## Features

- Minimal, content-first design
- Clean typography and readable layouts
- Responsive design for desktop and mobile
- Markdown-based writing with Jekyll
- Support for tags, footnotes, and RSS
- Sitemap generation with `jekyll-sitemap`

## Getting Started

### Requirements

- Ruby
- Bundler
- Jekyll

### Run Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/grisse/jekyll-theme-writeon.git
cd jekyll-theme-writeon
bundle install
```

Start the local development server:

```bash
bundle exec jekyll serve
```

Open `http://localhost:4000` in your browser.
